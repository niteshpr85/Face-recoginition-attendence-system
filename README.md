# Face Recognition Attendance System

## 📌 Overview
The **Face Recognition Attendance System** is an automated application that marks attendance by recognizing faces using a camera. It eliminates manual attendance, reduces proxy attendance, and improves accuracy and efficiency.

This system captures facial images, compares them with stored data, and records attendance with date and time.

---

## 🎯 Features
- Face detection and recognition using a webcam  
- Automatic attendance marking  
- Real-time face recognition  
- Stores attendance records in CSV/Database  
- Easy to use and efficient  
- Reduces human errors and proxy attendance  

---

## 🛠️ Technologies Used
- **Programming Language:** Python  
- **Libraries & Tools:**
  - OpenCV
  - NumPy
  - face_recognition
  - Pandas
  - datetime
- **Database/File Storage:** CSV file (can be extended to MySQL)
